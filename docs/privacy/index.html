Privacy Policy — Fly Earn Better Than You

Last updated: 2026-09-14

This page mirrors the repository privacy policy for Chrome Web Store submission. Canonical source: PRIVACY.md.

Summary

  • Fly is Paper-first and does not automatically submit real-money orders.
  • Most data stays on your device (IndexedDB / chrome.storage).
  • Optional Global Learning uploads anonymous Paper observations only after an explicit consent choice.
  • We do not sell data and do not use data for advertising.

What pages Fly can read

On supported trading pages (currently Binance Spot and Upbit, plus optional local demo / MaleCNS localhost), Fly may read page structure for UI detection, publicly visible market context, chart and BUY/SELL landmarks, and public market candle/feature data.

Why broker host permissions are needed

Host permissions allow Fly to detect supported pages, observe public market context, draw a non-interactive overlay, and run Paper simulation. Fly does not use <all_urls>.

Local storage

Language, Global Learning consent, Paper history, preferences, and an optional contribution queue are stored locally. IndexedDB remains the product source of truth for Paper/history.

Optional Global Learning (Supabase)

If you choose to share anonymous Paper results, privacy-filtered Paper observations may be batched to Supabase Edge Function ingest-learning-observation. Local-only mode makes no Global Learning upload requests. Product quality is identical either way.

What we do not collect / upload

  • Passwords, OTPs, cookies, session tokens, Authorization headers
  • Broker API keys or secrets
  • Email or personal identity
  • Account numbers, real balances, real holdings
  • Real-money / live-order history
  • Raw symbols in contribution payloads

Retention

Raw anonymous learning observations target 90 days. Local data remains until you clear it in the popup.

Changing consent / deleting local data

Use the Fly popup Global Learning radios to change consent, and Privacy actions to clear Paper history, contribution queue, or all local Fly data.

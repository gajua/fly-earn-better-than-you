# Paper Performance

Fly Performance metrics reuse Paper fills + PositionCycle history.

Metrics:

- Total realized PnL / return % (vs starting paper capital)
- Trades, wins, losses, break-even (neutral)
- Win rate, average win/loss %, best/worst trade %
- Profit factor (safe when losses are zero)
- Max drawdown on cumulative equity curve
- Brain-mode grouping (MaleCNS / Mock / Shuffled)

UI labels use **Experimental paper performance**. Historical paper results do
not imply future performance.

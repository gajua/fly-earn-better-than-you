# Release notes — v1.1.0

**Fly Earn Better Than You v1.1.0**

First public Chrome Web Store-oriented release packaging.

## Highlights

- MaleCNS-based experimental Fly overlay on supported trading screens
- Binance Spot **USABLE BETA**
- Upbit **USABLE BETA**
- Paper Trading default (virtual fills, local history)
- Shared **Global Calibration** preset (bundled `v1.0.0`)
- Optional anonymous community Paper contribution (explicit first-run consent)
- Korean / English UI
- Local Paper performance history (return, PnL, win rate, profit factor, drawdown, best/worst)
- No automatic live-order submission
- No broker API keys required for supported public observation
